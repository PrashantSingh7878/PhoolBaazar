🌸 Flower Farmer Marketplace

A modern frontend-based e-commerce web platform that connects flower farmers directly with buyers, eliminating middlemen and enabling fair trade. The application focuses on performance, responsiveness, and smooth user experience using modern UI design practices.

📌 Features

✅ Farmer & Buyer Registration/Login System
✅ Product Listing and Management Interface
✅ Shopping Cart with Persistent Storage
✅ Real-time Cart Updates
✅ Responsive UI for All Devices
✅ Smooth Animations and Transitions
✅ Clean and Modern User Interface
✅ Fast Load Time and Optimized Performance

🛠 Tech Stack

HTML5 – Structure and layout

CSS3 – Styling and layout design

JavaScript (ES6) – Core logic and dynamic behavior

Tailwind CSS – Responsive UI and modern styling

Local Storage & Session Storage – Cart persistence and state management

🎯 Project Objective

The main goal of this project is to bridge the gap between farmers and buyers by creating a digital marketplace that allows direct interaction without intermediaries. This improves transparency, pricing fairness, and accessibility for small-scale farmers.
